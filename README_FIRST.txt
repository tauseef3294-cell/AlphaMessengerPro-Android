Alpha Messenger Pro - Android APK build package

This is a source project, not an APK yet.

To build APK without installing Android Studio:
1) Create a GitHub repository and upload all files/folders from this package (including hidden .github folder).
2) Open the repository's Actions tab and run the workflow named Build Alpha Messenger Pro APK.
3) After it finishes successfully, open the run and download the APK artifact.

Website configured in the Android project: https://alpha.gt.tc/
