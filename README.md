# Alpha Messenger Pro Android

Android WebView app for https://alpha.gt.tc/.

## APK cloud build
1. Open the **Actions** tab.
2. Select **Build Alpha Messenger Pro APK**.
3. Click **Run workflow** on the main branch.
4. After the workflow finishes, download the **AlphaMessengerPro-debug-apk** artifact.

The workflow also runs on pushes to `main`.

## Package
- Application ID: `com.alphamessengerpro.app`
- Version: `1.0.0`
- Minimum Android: API 23 (Android 6.0)
